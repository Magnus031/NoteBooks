    几种值类型介绍

    Introduce

    左值和右值的区别含义

    二者其实存在本质区别

    • 左值 : 是一个可以 寻址 的对象，同时它并不会因为表达式的结束而失效。
    • 右值 : 是一个临时的对象，它在表达式结束后会被销毁。是不可寻址的。

    临时变量

    临时变量是指在某个作用域内使用的变量，它的生命周期仅限于该作用域。临时变量通常用于存储中间结果，以便在后续的计算中使用。由于临时变量的作用域有限，因此它们在使用后会被自动销毁，从而释放内存。

    临时变量 在 C++ 的规范中就是一个 右值。

    有关临时变量和引用的绑定

    临时变量只能绑定到常量引用上，不能绑定到非常量引用上。

    1
2
3
    const std::string& s = std::string("temporary"); // ok! const reference

std::string& s2 = std::string("temporary"); // error! non-const reference

    Matrix operator+(const Matrix& m1, const Matrix& m2) {
    Matrix result;
    // Perform addition
    return result;
}

int main() {
    Matrix m3 = m1 + m2;
}

    上面有一个细节，我们的 Line8 其实是有一定的 性能浪费的， 因为在完成了 operator+ 的重载创建了一个临时对象，然后我们又在这个表达式结束的时候需要将这个临时对象给 析构， 然后我们又创建了一个新的对象 m3， 这其实是有点浪费的。 就是说发生了一次析构，又发生了一次构造拷贝，尤其是对于如果这个结构体很大的时候，这种浪费就会更加明显。

    解决方法

    • 确保 Matrix 类支持移动构造和移动赋值 也就是 实现了移动语义， 这样的话就可以避免不必要的拷贝。

    • 开启 -O2/O3 优化选项，编译器会自动优化临时对象的生命周期，减少不必要的拷贝和析构。

    • 使用表达式模板（Expression Templates）

    • 使用智能指针来管理临时对象的生命周期，避免不必要的拷贝和析构。

    Matrix x = x1 + x2 的详细执行过程

    1. 首先，执行 x1 + x2，调用加法运算符，产生一个临时的 Matrix 对象（假设返回的是右值）。

    2. 然后，使用这个临时对象来初始化新变量 x。由于等号右边是一个右值（临时对象），编译器会选择调用移动构造函数 Matrix(Matrix&& a) 来初始化 x。

    3. 临时对象在语句结束后被销毁。

    重要的是：这里使用的是 = 的初始化语法，而不是赋值操作。在C++中，当使用 = 来声明并初始化一个新变量时，调用的是构造函数而非赋值运算符。

    与赋值操作的区别

    相比之下，如果是赋值操作，如下：

    1
2
    Matrix x;         // 默认构造x
x = x1 + x2;      // 这里是赋值，不是初始化

    这个过程会： 1. 先默认构造 x 2. 执行 x1 + x2 产生临时对象 3. 调用移动赋值运算符 operator=(Matrix&& a) 将临时对象赋值给 x 4. 临时对象被销毁

    为什么需要理解这种区别

    理解初始化与赋值的区别很重要，因为：

    1. 性能影响：在第一种情况（初始化）中，对象只构造一次。而在第二种情况（赋值）中，对象先默认构造一次，然后又被赋值，可能涉及资源释放和重新分配。

    2. 所需的函数：初始化依赖于构造函数，而赋值依赖于赋值运算符。

    3. 编写代码的方式：理解这种区别有助于编写更高效的代码。在适当的情况下，直接初始化通常比先默认构造再赋值更有效率。

    总结

    对于 Matrix x = x1 + x2：

    • 这是一个初始化操作，不是赋值
    • 只调用拷贝构造函数 Matrix(Matrix&& a)
    • 不涉及拷贝赋值运算符 operator=(Matrix&& a)

    这就是为什么虽然需要同时实现移动构造和移动赋值，但在不同的场景中使用的是不同的函数。初始化新变量时使用构造函数，更新已有变量时使用赋值运算符。

    几个动作

    拷贝赋值

    指的是对 operator=(const Matrix& a) 进行重载

    const Matrix& a 上述写的好处有两个:

    1. 既可以保证意外不发生，Matrix &a 可能会意外原始对象
    2. 可以传入 常量右值

    拷贝构造

    指的是对 Matrix(const Matrix& a) 进行重载
